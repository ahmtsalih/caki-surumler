# Çakı Pro sürümleri

Bu depo yalnızca **Çakı Pro** kurulum dosyalarını ve imzalı güncelleme bildirimini (`guncelleme.json`) dağıtır. Kaynak kod burada değildir.

- Kurulum dosyaları her sürümün **Releases** sayfasındadır.
- Program güncellemeyi yalnızca siz Ayarlar'dan açarsanız ya da "Şimdi denetle"ye basarsanız denetler. Bildirim imzalıdır; kurulum dosyası, boyutu ve SHA-256 özeti bildirimle tutmazsa kurulmaz.
- Lisans ve destek: cakiapplication@gmail.com
